# Jobs page: available tasks, recent runs, selected run log

Status: Approved
Date: 2026-10-23

## Context
The Jobs page currently separates Tasks and History into tabs, with large task cards and a complex run-detail presentation. The owner approved a simpler desktop mockup.

## Decision
The Jobs page has one unified view. At the top is a compact list of available background jobs, each showing its name, next scheduled run when applicable, and a Start now action. Beneath it is a compact Recent runs list showing timestamp, job title, duration and status. Selecting a run displays its details on the right, primarily as a concise, chronological list of timestamped log events describing what happened. The selected run is visibly highlighted. Keep navigation and responsive behavior coherent with MusicHub.

## Constraints
Show actual scheduler data and real persisted events, not fabricated progress or example jobs. Do not invent next-run times for manually triggered jobs. Preserve existing execution functionality and history; technical details may remain accessible where useful. Exact log retention and future scheduler editing are not decided.

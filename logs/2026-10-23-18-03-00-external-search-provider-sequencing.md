# External search provider extensibility

Status: approved by product owner, 2026-10-23.

Decision: External Search must support multiple catalog providers architecturally, but the initial implementation uses MusicBrainz only. Adding and reconciling further providers is deferred. No additional provider is approved yet.

Rationale: Ship a useful external search now without committing to premature provider selection or cross-source matching policy.

Open: Future providers, reconciliation, precedence, deduplication and source-specific quality policies.
